# 프로젝트(스코프) 관리

이 앱은 하나의 노트 워크스페이스 안에서 여러 프로젝트(게임 코드베이스, 외주 문서, 개인
기록 등)를 오갈 수 있게 "스코프 카탈로그"를 둔다.

## 구조

`scopes/` DB 폴더 (`kind: "scopes_board"`, 사용자에게는 "프로젝트 관리"로 보임). 각 행 =
프로젝트 하나다. 이 화면은 보드 보기를 지원하지 않는 고정 테이블이며, 사용자에게는
`프로젝트`(표시명)와 `경로`(파일시스템 경로) 두 열만 보인다. 표시명은 행의 `label`,
경로는 `path` frontmatter에 저장한다. 과거 `project` 그룹 값과 추가 속성이 파일에 남아
있더라도 프로젝트 관리 표에는 노출하지 않는다.

행의 **파일명(확장자 제외)이 곧 그 스코프의 id**다. 태스크 카드의 `scope` 필드는 이 id를
그대로 참조한다 (라벨을 바꿔도 파일명이 그대로면 참조가 깨지지 않음).

`path`를 설정하면 서버는 해당 프로젝트 루트의 실제 `AGENTS.md`를 확인하고, 없으면 즉시
기본 Markdown 파일을 만든다. 프로젝트 관리의 제목에 표시되는 프로젝트 이름을 클릭하면
카탈로그 행 노트가 아니라 이 `AGENTS.md`가 앱 편집기에 열린다. 저장할 때는 노트용 YAML
frontmatter를 붙이지 않고 프로젝트 파일 원문을 직접 수정한다. 등록되지 않은 경로나
심볼릭 링크 `AGENTS.md`는 외부 편집 대상으로 허용하지 않는다. 파일을 수정하면 해당
프로젝트의 기존 Codex 대화는 다음 요청에서 최근 대화를 인계한 새 스레드로 전환되어
갱신된 지침을 다시 읽는다.

## 실행 시 무슨 일이 일어나는가

태스크 카드에 `scope`가 지정돼 있으면, 실행 파이프라인이 그 스코프의 `path`를 조회해서
**그 경로를 codex의 작업 디렉토리(cwd)로 사용**한다. 따라서 코드·설정·테스트처럼 프로젝트
자체를 변경하는 작업은 그 프로젝트 폴더에서 수행한다. 단, 이 cwd는 분석 대상과 구현 산출물의
위치를 정하는 용도이지, 노트 앱이 관리하는 문서의 기본 저장소를 바꾸는 용도는 아니다.
프로젝트 루트의 `AGENTS.md`는 오케스트레이터가 본문을 복사해 붙이지 않고 Codex가 cwd 기준으로
직접 탐색한다.

`scope`가 없는 태스크(또는 채팅으로 직접 대화하는 경우)는 기본적으로 이 노트 워크스페이스
루트가 cwd다.

## 문서 산출물의 저장 위치

사용자가 “분석 문서를 만들어줘”, “요구사항/설계서/개발 계획서를 작성해줘”처럼 **노트 문서**를
요청한 경우에는 스코프가 있더라도 새 Markdown 파일을 외부 프로젝트의 `path`에 만들면 안 된다.
반드시 노트 워크스페이스 안에서 현재 섹션의 `items`에 등록된 알맞은 폴더에 저장한다. 예를 들어
`csmsp` 스코프를 분석한 결과는 `notes/csmsp/` 같은 `csmsp` 섹션 폴더에 둔다.

실행 프롬프트의 `# 문서 저장 대상 (반드시 준수)`에는 실제 절대 경로가 표시된다. 그 목록에서
내용에 맞는 폴더를 선택하고, 새 파일을 만들기 전과 만든 뒤에 경로가 그 폴더 아래인지 확인한다.
섹션을 판별할 수 없는 일반 대화만 노트 워크스페이스 루트를 기본 저장 위치로 사용한다.

예외는 사용자가 프로젝트 저장소 안의 파일을 명시한 경우다. 예를 들어 “`README.md`를 고쳐줘”,
“`docs/api.md`를 작성해줘” 또는 코드 변경과 함께 저장소의 개발 문서를 갱신해 달라고 한 요청은
그 프로젝트 경로에 작성한다. 요청이 단순 분석·정리인지 프로젝트 문서 변경인지 불명확하면 새
파일을 프로젝트에 만들지 말고 노트 섹션에 저장할 위치를 먼저 확인한다.

## 메모리

메모리는 워크스페이스 루트의 `MEMORIES.md` 한 파일로 관리한다. 앱은 섹션별 메모리 파일이나
사이드바 아이콘을 만들지 않는다. 사용자가 장기적으로 다시 참고할 사실이 있으면 `MEMORIES.md`를
일반 노트처럼 직접 만들고 편집할 수 있다. 전체 본문은 공통 프롬프트에 넣지 않고, 필요한 요청에서만
`search_memories`가 관련 구간을 제한된 길이로 반환한다.

## 이 매뉴얼을 읽고 있는 당신(에이전트)에게

지금 당신의 cwd가 노트 워크스페이스 루트가 아니라 특정 프로젝트 폴더라면, 그건 스코프가
지정된 태스크를 실행 중이라는 뜻이다. 그래도 노트 워크스페이스와 현재 섹션의 문서 저장 폴더는
쓰기 허용 경로로 함께 제공된다. 분석 결과를 문서화할 때는 cwd가 아니라 프롬프트의 `문서 저장
대상`을 사용한다.
