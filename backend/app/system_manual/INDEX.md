# 시스템 매뉴얼 목차

이 폴더(`.system-manual/`)는 이 노트 앱 자체의 조작법을 다룬다. 워크스페이스 내용(사용자
노트)이 아니라 **앱의 기능명세**이므로 사용자에게는 파일 트리에 보이지 않는다.

아래는 각 문서의 한 줄 설명이다. 지금 하려는 작업과 관련된 것이 있으면 그 파일을
`cat`/열어서 자세한 내용을 확인한 뒤 작업하라. 관련 없으면 무시해도 된다.

- `notes-and-blocks.md` — 노트 프론트매터 규칙, 콜아웃/토글/DB뷰/mermaid 등 이 앱 전용 마크다운 문법
- `databases.md` — DB 폴더(`.db.json`) 스키마, 셀 타입, 태스크 보드·프로젝트 관리 프리셋
- `task-board.md` — 태스크 보드 상태 흐름과 카드 프론트매터 규칙 (카드를 만들거나 상태를 바꿀 때 필수)
- `projects-and-scopes.md` — 여러 프로젝트(스코프) 관리, cwd 격리와 노트 문서 저장 위치
- `erd-designer.md` — ERD 테이블 설계 파일(`.erd.json`) 생성·수정 규칙과 DDL 가져오기/내보내기 사용법

이 문서들은 앱이 자동으로 동기화하므로 직접 수정해도 다음 실행 때 덮어써진다. 워크스페이스
루트에서만 접근 가능하며, 스코프가 지정된 태스크(외부 프로젝트 코드베이스에서 실행되는
작업)에서는 cwd가 이 폴더 밖이라 접근할 수 없다.
